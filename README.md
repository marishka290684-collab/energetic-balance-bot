# Telegram-бот «Энергетический баланс и телесные маркеры»

Это версия исходного бота, подготовленная для размещения на Render через Telegram Webhook.
Тексты теста, 6 вопросов, варианты ответов и расчёт результата сохранены.

## Настройки Render

Создайте **Web Service** из этого Git-репозитория и укажите:

- Runtime: Python 3
- Build Command: `pip install -r requirements.txt`
- Start Command: `python bot.py`
- Plan: Free

В разделе Environment добавьте переменную:

- Key: `BOT_TOKEN`
- Value: токен от @BotFather

Render автоматически предоставляет `RENDER_EXTERNAL_URL` и `PORT`.
Секрет вебхука генерируется приложением при запуске и не требует ручной настройки.

## Важно о бесплатном тарифе

Бесплатный Web Service Render засыпает после 15 минут без входящего трафика.
При следующем обращении запуск может занять около минуты. Render также может перезапускать
бесплатный сервис. Ответы пользователей хранятся только в памяти и теряются при перезапуске.

## Безопасность

Не добавляйте токен в файлы проекта и не отправляйте его в чат. Храните его только
в Environment Variables на Render.
